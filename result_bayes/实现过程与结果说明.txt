Bayes 三分类实现过程与结果说明
============================================================

一、实现目标
本方法用于完成 cloudy、sandstorm、sunny 三类彩色天气图像分类。
与前两种深度学习方法不同，这里采用传统机器学习流程：人工特征提取 + PCA 降维 + Bayes 分类。

二、实现流程
1. 读取 data/train、data/val、data/test 三个数据划分。
2. 对每张彩色图像提取 40 维人工特征。
3. 先在训练集和验证集上搜索最优 PCA 主成分数。
4. 用训练集和验证集合并后的样本重新训练最终 Bayes 分类器。
5. 在测试集上输出分类报告、混淆矩阵、指标图和样本可视化结果。

三、特征设计说明
1. GLCM 纹理特征：
   灰度图先量化为 16 级，在 0°、45°、90°、135° 四个方向上构建灰度共生矩阵。
   每个方向提取熵、能量、对比度、一致性 4 个统计量，共得到 16 维纹理特征。
2. RGB 颜色特征：
   对 R、G、B 三个通道分别计算均值、方差、标准差、最大值、非零比例、中位数、偏度、峰度。
   每个通道 8 维，三个通道共得到 24 维颜色特征。
3. 最终特征维数：16 + 24 = 40 维。

四、降维与分类说明
1. 先对特征做标准化，再进行 PCA 降维，避免不同量纲影响主成分分解。
2. 候选 PCA 维数通过验证集准确率进行筛选。
3. 本次实验选出的最优 PCA 维数为 32。
4. 最终分类器采用 Gaussian Naive Bayes，即高斯朴素贝叶斯分类器。

五、数据规模
训练集样本数：9472
验证集样本数：1260
测试集样本数：1256

六、结果说明
1. PCA 后累计解释方差：0.999850
   该指标表示 PCA 保留下来的主成分一共解释了原始特征中多少比例的信息。
   本实验中取 32 个主成分后，仍保留了约 99.985% 的原始特征变化信息，
   说明降维后信息损失很小，PCA 主要起到了压缩冗余和减弱特征相关性的作用。
2. 验证集最优准确率：0.684127
3. 测试集准确率：0.710191

七、与无 PCA 的对比
1. 无 PCA 验证集准确率：0.576984
2. 无 PCA 测试集准确率：0.654459
3. 使用 PCA 的测试集准确率：0.710191
4. PCA 相比无 PCA 的测试集准确率提升：0.055732
5. 对比结论：
   不使用 PCA 时，Bayes 分类器可以完成三分类任务，但整体准确率更低。
   引入 PCA 后，特征冗余和相关性被压缩，分类结果更稳定，最终测试精度更高。

八、使用 PCA 后的各类别表现
cloudy: precision=0.6227, recall=0.8706, f1-score=0.7261, support=510
sandstorm: precision=0.7717, recall=0.6147, f1-score=0.6843, support=231
sunny: precision=0.8524, recall=0.5942, f1-score=0.7002, support=515

九、无 PCA 的各类别表现
cloudy: precision=0.7450, recall=0.2922, f1-score=0.4197, support=510
sandstorm: precision=0.7556, recall=0.8831, f1-score=0.8144, support=231
sunny: precision=0.5967, recall=0.9107, f1-score=0.7210, support=515

十、结果文件说明
1. classification_report.txt：测试集分类报告。
2. classification_report_no_pca.txt：无 PCA 对照实验的测试集分类报告。
3. evaluation_metrics.txt：总体指标摘要，含是否使用 PCA 的对比结果。
4. confusion_matrix.png / confusion_matrix.csv：混淆矩阵图与表。
5. learning_curves.png：PCA 维数搜索和解释方差曲线。
6. evaluation_metrics.png：各类别 precision、recall、f1-score 柱状图。
7. sample_predictions_grid.png：测试样本预测拼接图。
8. *_FN.png：典型误分类样本图。
9. best_bayes_pipeline.joblib：保存的标准化器、PCA 和 Bayes 分类器。

十一、方法特点说明
该方法不依赖深度神经网络训练，解释性较强，适合与 CNN、ResNet 做传统方法对比实验。
但由于人工特征表达能力有限，其最终精度通常会低于表现较好的深度学习模型。
